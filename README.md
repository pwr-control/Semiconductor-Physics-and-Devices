# Semiconductor Physics and Devices

Fundamental solid-state physics, written up from the point of view of a power-electronics and control engineer. This repository collects the work of a fundamental nature: explanatory notes, plain-English rewrites of technical documents, derivations, and the scripts that make their figures.

## Contents

| Folder | Topic |
|---|---|
| [`diode-reverse-recovery/`](diode-reverse-recovery/) | Reverse recovery of high-voltage diodes: the DS1112SG60 PLECS/Simscape parameter note (original Italian PDF and a plain-English version) and a companion document on the physics of stored charge and recovery. |

## Conventions

- When a technical document is rewritten in simpler language, the original is kept next to the rewrite.
- Documents are Markdown with LaTeX math (rendered by GitHub). Figures are SVG, generated by a script kept in the same folder, so they can be regenerated and modified.
